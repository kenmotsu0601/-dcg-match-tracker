# DCG 戦績管理 v3

ビルド不要の静的Webアプリです。`index.html`、`manifest.json`、`sw.js` をGitHub Pagesの公開対象ディレクトリに置いて使用します。

## 主な仕様
- 環境ごとにデッキ・対戦記録を分離
- 過去環境へ自由に切り替えて記録を再開可能
- 環境名の変更
- 先攻/後攻と勝敗を分けて選択し、登録ボタンで確定
- 最新環境の戦績を通常表示し、過去環境は折りたたみ
- 戦績は「戦績 / 対面別」の2タブ
- デッキ別の折りたたみ見出しに総合勝率を表示
- 戦績の日付フィルタ
- 履歴は「総合 / 先攻 / 後攻」切替、勝敗色分け
- 履歴削除は「詳細」を開いた中から実行
- 同一環境内の同名デッキ重複登録を防止

既存のv2データは同じLocalStorageキーを使用するため、そのまま引き継がれます。
